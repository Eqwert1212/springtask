# Проверка зависимостей — 20 сентября 2026

Spring Boot обновлён с 3.1.5 до 4.0.8, Gradle — с 8.3 до 8.14.3.
Java 17 сохранена. Для модульной структуры Boot 4 используются отдельные
стартеры Web MVC, Security и Flyway и соответствующие тестовые стартеры.
Flyway использует отдельный модуль PostgreSQL. Версия Thymeleaf Layout Dialect
теперь определяется BOM Spring Boot, а не отдельной устаревшей фиксацией.

Выполнена сверка разрешённых Maven-координат `runtimeClasspath` с OSV API
(`/v1/querybatch`). Проверяется именно набор версий, выбранных Gradle,
включая транзитивные зависимости. Исходный код и локальные настройки подключения
в запрос не передаются.

При первом запуске обнаружены три предупреждения для Tomcat 11.0.24:

- [GHSA-9xv2-5v5q-p794](https://osv.dev/vulnerability/GHSA-9xv2-5v5q-p794)
- [GHSA-gcx9-497g-6cp6](https://osv.dev/vulnerability/GHSA-gcx9-497g-6cp6)
- [GHSA-h3x4-894j-xpx5](https://osv.dev/vulnerability/GHSA-h3x4-894j-xpx5)

Исправленная версия для ветки 11 — 11.0.25. В `build.gradle` временно задана
общая `tomcat.version`, чтобы согласованно обновить все модули Tomcat.
После следующего обновления BOM этот override следует пересмотреть.
Эти предупреждения относятся к механизмам авторизации Tomcat; их наличие
не означает, что все соответствующие сценарии доступны в данном приложении.

Проверка OSV — снимок известных сведений на указанную дату, а не гарантия
отсутствия уязвимостей. Она не охватывает установленную JDK, сервер PostgreSQL,
Docker-образ, ОС и ошибки логики приложения. Для своей среды используйте
актуальное исправление JDK 17 и регулярно повторяйте проверку зависимостей.

Источники: [рекомендации миграции Boot](https://github.com/spring-projects/spring-boot/wiki/Spring-Boot-4.0-Migration-Guide),
[Tomcat security](https://tomcat.apache.org/security-11.html).
